# หนังสือเรียนภาษามลายู อต.6 · Buku Teks Bahasa Melayu Tahun 6

เว็บไซต์หนังสือเรียนภาษามลายู ชั้นปีที่ 6 หลักสูตรอิสลามศึกษาตอนต้น (อต.6)
เนื้อหาตรงกับหนังสือเล่ม (ไฟล์ Word) ใช้ภาษามลายูมาตรฐานทั้งหมด

เรียบเรียงโดย ผศ.มูหำหมัด สาแลบิง · สาขาวิชาภาษามลายู คณะมนุษยศาสตร์และสังคมศาสตร์ มหาวิทยาลัยทักษิณ

## มีอะไรในเว็บไซต์

- บทเรียน 12 บท (`pelajaran/01.html` – `12.html`): กิจวัตรประจำวันของฉัน · กีฬา · ความใฝ่ฝันของฉัน · งานอดิเรกของฉัน · การลักขโมยเป็นบาป · สัตว์ฮะลาลและฮะรอม · ซะกาตและฮัจญ์ · สุภาษิตและสำนวน · การแต่งประโยคสั้น · คำพ้องความหมายและคำตรงข้าม · คำรากฐานและคำเติม · บทกลอนปันตุน
- ภาพประกอบคำศัพท์ที่เป็นสิ่งของรูปธรรม (`assets/gambar/` ดูที่มาและสัญญาอนุญาตใน `LICENSE.txt`) แสดงในตารางคำศัพท์ บัตรคำ อภิธานศัพท์ และคำศัพท์วันนี้
- ปุ่มฟังเสียงคำศัพท์ (ใช้ระบบอ่านออกเสียงของเครื่อง)
- แบบฝึกหัดพร้อมปุ่ม “ดูเฉลย” แบบทดสอบตนเอง และบัตรคำท้ายบท
- อภิธานศัพท์พร้อมช่องค้นหา (`glosari.html`)
- ปุ่ม "Muat turun PDF / ดาวน์โหลด PDF" ในแต่ละบท (ไฟล์อยู่ในโฟลเดอร์ `pdf/`)

## หลักการสะกดอักษรยาวี

ตัวสะกดยาวีทั้งหมดใช้หลักตาม *Pedoman Umum Ejaan Jawi Bahasa Melayu* ของ Dewan Bahasa dan Pustaka (DBP) และตรวจกับ PRPM DBP (https://prpm.dbp.gov.my/)

## วิธีแก้ไขเนื้อหา

เนื้อหาทั้งหมดอยู่ในไฟล์ `_src/data/at6.js` ไฟล์เดียว
ข้อความสองภาษาเขียนแบบ `"ภาษามลายู||ภาษาไทย"` (คั่นด้วยเครื่องหมาย `||`) เว็บจะแสดงภาษามลายูบรรทัดบน ภาษาไทยบรรทัดล่าง
หลังแก้แล้วให้รันคำสั่งนี้ในโฟลเดอร์หลักของ repo เพื่อสร้างหน้าเว็บใหม่ (ต้องติดตั้ง Node.js ก่อน)

```
node _src/build.js
```

ถ้าแก้คำผิดเล็กน้อย จะแก้ในไฟล์ `.html` บนหน้า GitHub โดยตรงก็ได้ แต่ถ้ารัน `build.js` ภายหลัง ส่วนที่แก้ใน `.html` จะถูกเขียนทับ

## ไฟล์ PDF ของแต่ละบท

ไฟล์ `pdf/pelajaran-01.pdf` – `12.pdf` สร้างจากหน้าเว็บบทเรียน (ขนาด A4 ไม่มีเฉลย แบบทดสอบ และบัตรคำ)
เมื่อแก้เนื้อหาบทเรียนแล้ว ต้องสร้าง PDF ใหม่ด้วย ไม่อย่างนั้นไฟล์ PDF จะยังเป็นเนื้อหาเดิม

```
node _src/build.js
python3 _src/pdf.py
```

(ต้องติดตั้ง Python และ `pip install playwright` แล้ว `playwright install chromium` ก่อน)

## SEO (ให้ค้นหาเจอใน Google)

- ทุกหน้ามีชื่อหน้า คำอธิบาย ลิงก์หลัก (canonical) ข้อมูลสำหรับแชร์ (Open Graph) และข้อมูลโครงสร้าง (schema.org) สร้างอัตโนมัติจาก `_src/build.js`
- `sitemap.xml` สร้างใหม่ทุกครั้งที่รัน `node _src/build.js`
- รูปที่แสดงเมื่อแชร์ลิงก์: `assets/share.png`
- รหัสยืนยัน Google Search Console ใส่ที่บรรทัด `const GOOGLE_VERIFY = ...` ในไฟล์ `_src/build.js`
